## About RHB Digital

RHB Digital is a software development and digital consulting business based in **Östersund, Sweden**, founded by **Richmond Boakye**, a Microsoft Certified Azure Developer Associate (AZ-204).

We help small businesses turn practical requirements into websites, integrations and custom software. Projects are led directly by Richmond, from scoping and implementation to testing, deployment and handover. Communication is available in English and Swedish.

## What we build

| Service | How we can help |
| --- | --- |
| **Backend systems & APIs** | C# and ASP.NET Core APIs, PostgreSQL/EF Core, authentication and third-party integrations. |
| **Azure integrations** | Azure Functions, Service Bus and Blob Storage for connected business workflows. |
| **Shopify stores** | Liquid sections, theme customization, mobile layout improvements, store configuration and booking integrations. |
| **Business websites** | WordPress websites and custom themes tailored to the business. |
| **Automation & maintenance** | Python tools, API integrations, testing, debugging and improvements to existing applications. |
